Pair geometry

Per-pair geometry is built once per pool pair and shared by every selector and refit. Pools are stored in VisualGeometryCore's NormalizedImageFrame (image centre, half diagonal); essential-matrix problems work on the unit bearings the pool-frame camera back-projects.

LocalOptimizationDoneRight.PairGeom — Type
PairGeom

Per-pair calibration and ground truth, the context that scores a pool model's pose error. It scores any stored pool-frame fundamental's coherent imc pose error and holds the pool-frame csponds cs (x1 => x2) the truncated-family LO feeds to PoseLib's pixel-form refine_relpose with Kc. The cheirality vote reads bearings from the E problem instead (essential_bearings).

LocalOptimizationDoneRight.PairCtx — Type
PairCtx

Everything the refit layer needs about one pair. Built ONCE per pair by build_pair_ctx and reused across every (LO refit spec × grid column), it holds the pair itself (a light PoolPair), its pool-frame problem (ep), the optional RelposeBundleProblem (bp, nothing unless bundle=true), the geometry, and the scoring context (problem_type, prior).

LocalOptimizationDoneRight.build_pair_ctx — Function
build_pair_ctx(problem_type, pair::PoolPair; prior = IGPrior(0.0, 0.0), bundle = false) -> PairCtx

Build the PairCtx of one pool pair, once. It holds the family's pool-frame problem (RobustVisualGeometry's EssentialProblem(pair), FundMatProblem(pair) or HomographyProblem(pair)), Kc, GT pose and pool-frame points; plus the Schur bundle problem when bundle = true. problem_type is the pool's track (problem_type(pool.problem)).

LocalOptimizationDoneRight.problem_type — Function
problem_type(p::Symbol) -> Type

The RANSAC problem type of a two-view pool track: :E → EssentialProblem, :F → FundMatProblem, :H → HomographyProblem. The one map from a track's letter (a pool's problem) to its problem class — the value a PairCtx carries as problem_type; any other symbol is an ArgumentError. Inside a function, name the result P (a local problem_type would shadow this function).

LocalOptimizationDoneRight.model_imc — Function
model_imc(model, geom::PairGeom) -> Float64
model_imc(model, ctx::PairCtx)   -> Float64

The pose error [deg] of model against the pair's ground truth. By the model's type: a metric EssentialMat → max(Δr, Δt) of its best decomposition; a pool-frame FundMat → the same after the pool-frame calibration upgrade; a pool-frame HomographyMat → the optimistic decomposition ROTATION error.

LocalOptimizationDoneRight.essential_bearings — Function
essential_bearings(ctx::PairCtx) -> (f₁, f₂)

The unit bearings of an E context's problem — what cheiral_pose_fast votes on (RVG bd69092 dropped its Kc pair). Read from ctx.ep, which already back-projected every cspond through the pool camera, rather than re-derived. Only an E context has bearings: on an F or H context ctx.ep holds pool pixels, so this refuses rather than hand 2-vectors to a ray test.

LocalOptimizationDoneRight.perturbed_pose — Function
perturbed_pose(rng, R_gt, t_gt, δ) -> (RotMatrix, Vec3)

The protocol's δr = δt = δ perturbation: rotation by δ [rad] about a seeded random axis plus a magnitude-δ translation jitter (t re-normalized). The draw order is fixed (axis first, then translation jitter), so a caller-seeded rng reproduces the seed bit-for-bit (ladder convention: one StableRNG(stable_seed(seed, scene, pair, δ)) per (pair, δ), so every arm sees the identical perturbed seed, on every Julia version). Owned here since VisualGeometryCore 0.18 dropped Synthetic.perturb_pose (this was its only caller); the body is that function's, verbatim, with δr = δt = δ.
